# Game of Life

Консольная реализация игры Conway's Game of Life на языке C с использованием ncurses.

## Требования

- Linux или другая Unix-подобная система;
- GCC;
- GNU Make;
- библиотека ncurses;
- терминал размером не меньше 80x25.

## Сборка

```bash
make
```

Для полной пересборки:

```bash
make rebuild
```

Для удаления исполняемого файла:

```bash
make clean
```

## Запуск

Начальное поле передается через стандартный ввод:

```bash
./game_of_life < patterns/glider.txt
```

Поле должно содержать ровно 25 строк по 80 символов. Границы поля замкнуты: после последнего столбца идет первый, а после последней строки — первая. Допустимые символы:

- `0` — мертвая клетка;
- `1` — живая клетка.

## Управление

- `A` или `a` — увеличить скорость;
- `Z` или `z` — уменьшить скорость;
- `Space` — завершить игру.

Живые клетки отображаются символом `O`, мертвые клетки — пробелом.

## Проверки

Форматирование исходного файла:

```bash
make format
```

Проверка форматирования без изменения файла:

```bash
clang-format --dry-run --Werror src/game_of_life.c
```

Статический анализ при установленном cppcheck:

```bash
cppcheck --enable=all --suppress=missingIncludeSystem src/game_of_life.c
```
