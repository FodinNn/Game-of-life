# Начальные конфигурации

В этой папке находятся готовые начальные состояния игрового поля.

Каждый файл содержит ровно 25 строк. В каждой строке ровно 80 символов:

- `0` означает мертвую клетку;
- `1` означает живую клетку.

Доступные конфигурации:

- `glider.txt` — планер;
- `blinker.txt` — мигающая фигура;
- `block.txt` — неподвижный блок;
- `beacon.txt` — маяк;
- `toad.txt` — жаба.

Запуск:

```bash
make
./game_of_life < patterns/glider.txt
```

Для завершения игры нажмите пробел.
